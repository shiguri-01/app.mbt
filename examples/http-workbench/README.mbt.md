# HTTP/API Workbench

Desktop example using MoonBit native host code, `moonbitlang/async/http`, JSON
state persistence, Rabbita, and Vite.

Build the frontend first:

```sh
npm --prefix examples/http-workbench install
just build-http-workbench-frontend
```

Run the desktop app:

```sh
just run-http-workbench-example
```
